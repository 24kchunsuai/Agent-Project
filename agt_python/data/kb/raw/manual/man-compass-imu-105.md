# 指南针与 IMU 校准方法及干扰处置

## 一、两个传感器分别管什么

- **指南针（磁力计）**：提供机头朝向的绝对参考，决定飞行器「知道自己在朝哪飞」
- **IMU（惯性测量单元）**：由加速度计与陀螺仪组成，感知姿态与加速度变化，决定飞行器「知道自己是水平的还是在倾斜」

两者配合 GNSS 才能实现稳定悬停与自动返航。任何一个异常，轻则漂移，重则失控。

## 二、指南针校准

### 2.1 何时需要校准

- 首次使用或更换新场地（与上次起飞地点相距较远，通常 > 数十公里）
- App 提示「指南针异常/需要校准」
- 飞行中出现「指南针受干扰」警告
- 机身后更换过部件、摔机维修后

### 2.2 校准方法

1. 选择空旷、远离磁干扰的场地
2. 在 App 中进入「指南针校准」
3. 手持飞行器**水平旋转 360°**（保持水平，机身绕竖直轴转）
4. 随后**竖直旋转 360°**（机身绕水平轴翻转，机头朝下/朝上各一次）
5. 校准成功的标志是 App 提示完成，且状态栏无红色警告

### 2.3 校准失败的原因与对策

| 原因 | 对策 |
|---|---|
| 靠近钢筋、金属结构、车辆 | 换到开阔地面，远离金属 |
| 身上携带磁铁（手表、腰带扣、手机磁吸支架） | 取下随身磁源 |
| 地下有管线/电缆 | 换位置 |
| 附近有高压线、基站 | 至少远离数十米 |
| 指南针模块硬件故障 | 送修，不要反复尝试 |

## 三、IMU 校准

**何时需要**：App 提示 IMU 异常；飞行器发生碰撞后；长时间未使用；姿态球显示异常。

**校准要求**：必须放在**水平、稳定、无振动的平面**上（不要放在倾斜地面或晃动桌面），校准过程中不要触碰飞行器。不同机型的校准姿态序列由 App 引导完成。

**注意**：IMU 校准不能频繁做，也不要在地面不水平的地方做，否则会引入新的偏差。

## 四、飞行中遇到指南针干扰怎么办

### 4.1 症状

- App 弹出「指南针受干扰，请尽快降落在安全位置」
- 姿态球显示机头方向与实际不符
- 飞行器开始画圈、漂移、不按指令方向移动

### 4.2 处置步骤（按优先级）

1. **立即切换姿态模式（ATTI）**，脱离指南针参与的控制回路，改为手动操控
2. **降低高度、减小水平机动**，不要做大幅度转向
3. **尽快在最近的空旷安全位置降落**
4. 若在高空且无法判断方向，可使用地图上飞行器图标与自身位置的相对关系判断方位
5. 落地后重新校准指南针，再决定是否继续飞行

**关键原则**：出现指南针干扰时，**不要依赖自动返航**——返航依赖方向判定，方向错误会导致飞向错误方向。

## 五、容易忽视的干扰源

- 车身、车顶（钢板/铝合金）上起飞
- 大型金属平台、集装箱、脚手架
- 靠近磁吸手机支架、音箱、磁铁工具
- 雷雨天气前后的电磁环境变化
- 地下车库、隧道口、桥底

## 六、常见问题

**问：每次都要校准指南针吗？**
答：不需要。频繁校准反而可能引入偏差。只在更换场地、App 提示异常、或出现干扰警告时校准。

**问：校准后仍然提示异常怎么办？**
答：先排除环境因素（换场地、清磁源）。若仍异常，说明可能是硬件故障，应停止飞行并送修。

**问：IMU 校准需要注意什么？**
答：必须放在水平、稳定、无振动的平面上，不要倾斜、不要晃动、不要在地毯等软表面上做。
