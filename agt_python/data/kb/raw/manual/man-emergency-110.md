# 飞行应急处置预案

## 一、原则

**人身安全永远优先于设备安全。** 任何情况下，处置的第一目标是不伤及他人、不造成更大范围损害，飞行器本身是可替换的资产。

## 二、失控（飞行器不响应操控）

**症状**：推杆无响应、飞行器自行运动、姿态异常。

**处置步骤**：
1. 检查遥控器天线朝向、与飞行器之间是否有遮挡
2. 尝试切换飞行模式（如切到姿态模式取回手动控制）
3. 若完全无响应，**触发自动返航**（若链路仍部分可用）
4. 若返航也无效，且飞行器朝人群或危险区域飞去，应立即**疏散人员**并报警
5. 记录最后可见位置与飞行方向，便于后续寻找

**关键**：不要在失控时反复猛打杆，可能加剧姿态混乱。

## 三、失联（图传与遥控同时中断）

1. 保持冷静，**不要移动**（移动会让你与飞行器的相对位置变化，影响自动返航的返航点判断）
2. 等待失控保护触发（通常数秒后自动返航）
3. 观察天空，等待飞行器自动飞回
4. 若长时间未返回，使用 App 的「找飞机」功能（读取最后已知坐标）
5. 记录坐标后前往寻找，注意安全不要进入危险区域

**预防**：起飞前确认失控保护设为「返航」，返航高度高于沿途障碍，并确保电量足够返航。

## 四、坠机

1. **先确认是否有人受伤**。若有人员受伤，立即拨打急救电话，优先救治
2. 关闭飞行器电源，避免电机持续空转或短路
3. **拔下电池**，将电池单独放置在远离可燃物的开阔处观察（锂电池可能延迟起火）
4. 拍摄现场照片，记录坠落位置与状态
5. 若在道路、公共区域，尽快移除残骸避免二次事故
6. 若涉及第三方财产损失，依规协商处理并联系保险

## 五、电池起火

1. **不要用手直接接触**燃烧中的电池
2. 若火势小，可用**大量水**降温（锂电池需要降温而非隔绝氧气），或用专用灭火器
3. 大量冒烟时立即疏散人员并报警
4. 燃烧后的电池会释放有毒气体，避免吸入，处理后开窗通风
5. 不要将冒烟/起火的电池放入密闭空间或车内

## 六、进入禁飞区或接到警告

1. 若 App 提示进入限制区域，立即**停止前进并后退**
2. 若收到管理部门或警方的劝阻，立即降落并配合
3. 不要试图通过拉高高度或关闭 GPS 绕过限制

## 七、天气突变

| 情形 | 处置 |
|---|---|
| 突降大雨 | 立即就近降落，不要试图返航到远处；雨水会导致电机与电路损坏 |
| 强风 | 降低高度（高空风速更大），以姿态模式手动操控返航，注意电量消耗 |
| 雷电临近 | 立即降落收机，不要在开阔地停留 |
| 能见度骤降 | 降低高度、缩短距离，依靠图传与地图返航 |

## 八、事故后的复盘要点

1. 记录时间、地点、机型、电池循环、天气、飞手操作序列
2. 导出飞行记录（App 飞行日志通常包含轨迹、高度、速度、告警）
3. 判断是否属于产品缺陷（保留残骸与日志用于厂商检测与索赔）
4. 若涉及责任纠纷，保留现场证据与保险单据
5. 将结论写回检查清单，避免同类问题重复发生
