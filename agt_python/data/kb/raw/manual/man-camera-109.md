# 相机参数设置与媒体存储管理

## 一、关键拍摄参数

| 参数 | 说明 | 场景建议 |
|---|---|---|
| 分辨率 | 照片像素 / 视频规格 | 需二次裁剪选高像素；成片直出可按平台要求 |
| 帧率 | 每秒帧数 | 常规 30fps；动作场景 60fps 以上便于慢放 |
| 快门 | 曝光时间 | 视频遵循「2 倍帧率」法则（如 30fps 用 1/60s）获得柔和运动模糊 |
| ISO | 感光度 | 尽量用原生低 ISO（如 100）保证画质；暗光下权衡噪点 |
| 白平衡 | 色温 | 优先固定白平衡而非自动，避免画面色温跳变 |
| 色彩模式 | 普通 / 高动态范围 / 对数（Log/HLG） | 直出选普通；后期调色选对数模式 |
| 码率 | 视频数据率 | 高码率利于后期，但占用存储大 |

## 二、ND 滤镜的使用

航拍视频规则的快门速度要求（1/60s 等）在白天强光下会导致过曝，此时需用 **ND 滤镜（中性密度滤镜）** 减光：

- ND8：约减 3 挡，适合微阴
- ND16：约减 4 挡，适合晴天
- ND32 / ND64：强光环境

**用途区分**：ND 滤镜主要用于**视频**获得稳定运动模糊；**拍照**通常不需要长时间曝光时可不用。

## 三、拍摄中的实用设置

1. **直方图/斑马纹**：开启以判断曝光，避免高光溢出
2. **网格线**：辅助构图（三分法）
3. **峰值对焦/自动对焦**：切换手动与自动对焦确认焦点
4. **曝光锁定**：避免飞行中曝光跳变
5. **电子防抖与画面裁切**：防抖会裁切画幅，按需取舍
6. **竖拍模式**：适配短视频平台，注意会裁切画幅与降低画质

## 四、存储管理

### 4.1 存储卡选择

- 使用 **U3 / V30 以上**速度等级的卡，低速卡会导致高码率视频丢帧或录制中断
- 容量按任务时长估算：高码率 4K 视频每分钟可能占用数百 MB
- 优先选择品牌卡，杂牌卡存在掉盘、写入错误风险

### 4.2 使用规范

1. 格式化在**飞行器内**完成（而非电脑上），确保文件系统匹配
2. 每次开飞前确认剩余空间
3. 不要飞行中拔卡
4. 导出素材用读卡器，不要反复插拔飞行器接口

### 4.3 机载内存与缓存

部分机型不带机载内存，也有机型提供少量内置存储或低码率缓存（用于 App 预览与找回）。**缓存不可替代存储卡**，画质与分辨率通常低于原始录制。

## 五、素材备份流程

1. 落地后先**复制**到电脑/移动硬盘，不要「剪切」
2. 按「日期-地点-任务」建立目录结构
3. 确认备份完整后再格式化存储卡
4. 重要素材做双备份（本地 + 移动硬盘/云）

## 六、常见问题

**问：录制中途自动停止了？**
答：常见原因是存储卡速度不足、卡已满或卡出现写入错误。应更换符合速度等级的卡并检查剩余空间。

**问：画面拍摄时出现果冻效应（画面扭曲）怎么办？**
答：多见于运动挡高速飞行或机身振动，可降低飞行速度、检查桨叶动平衡与云台减震件。

**问：Log 模式拍的素材很灰是正常的吗？**
答：正常。对数（Log）模式保留更多高光与暗部细节，但对比度与饱和度低，需要后期还原（套用官方 LUT 或手动调色）才可用。
