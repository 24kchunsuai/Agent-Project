# 飞行模式说明

## 一、为什么必须理解飞行模式

飞行模式决定了飞行器使用哪些传感器做定位与稳定，直接关系到操控手感与安全边界。新手最危险的动作就是**在无 GPS 环境下误以为有 GPS**，导致飞行器飘走而无法自主悬停。

## 二、主要飞行模式

### 2.1 GPS 模式（P 挡 / 普通挡，默认）

- **定位依据**：GNSS（GPS + GLONASS + Galileo 等）+ 下视视觉
- **特点**：可自主悬停，松杆即停，抗风能力最强，支持自动返航
- **适用**：绝大多数常规飞行场景
- **前提**：卫星数充足（一般 ≥ 10 颗）

### 2.2 姿态模式（ATTI）

- **定位依据**：仅靠 IMU 气压计保持姿态，**无水平位置锁定**
- **特点**：松杆后会随风漂移，需持续手动修正；高度仍可稳定
- **触发场景**：卫星信号不足、指南针受干扰、视觉定位失效
- **风险**：新手容易因不习惯漂移而过度修正，导致失控坠机
- **应对**：一旦进入姿态模式，应立即降低高度、减少水平机动，寻找开阔地降落，**不要试图飞远**

### 2.3 运动挡（S 挡 / Sport）

- **特点**：解除部分限速与限高，速度、加速度、上升下降速率明显提升
- **代价**：避障系统通常**不生效或降级**；图传码率提高但抗干扰下降；耗电显著加快；拍摄画面容易果冻/倾斜
- **适用**：赶时间、跟拍快速移动目标
- **建议**：不在陌生环境、不在人群附近使用

### 2.4 平稳挡（C 挡 / Cine）

- **特点**：限速、限加速，飞行动作极平滑
- **适用**：需要稳定运镜的视频拍摄
- **代价**：抗风能力下降，强风下不建议使用

### 2.5 其他模式

- **智能飞行模式**：一键短片、跟随、环绕、航点任务等，属于自动化功能而非飞行模式
- **返航模式（RTH）**：触发后自动爬升到返航高度并飞回返航点

## 三、模式切换注意事项

1. 切换挡位前后要**平稳过渡**，不要在满杆时突然切运动挡
2. 从 GPS 模式意外进入姿态模式时，App 通常会有提示，需立即关注
3. 运动挡飞行后切回普通挡，飞行器会有制动动作，注意前方净空
4. 部分机型的挡位切换开关在遥控器侧面，误触后可能改变飞行特性

## 四、新手实操建议

1. **首次飞行只用 GPS + 普通挡**，在开阔场地熟悉手感
2. 熟悉「姿态模式」下的操控——可以主动在安全场地（如无风草地）模拟，建立肌肉记忆
3. 不要在飞行中途尝试未使用过的模式
4. 强风、雨雪、雾霾天气降低飞行等级或取消飞行

## 五、常见问题

**问：为什么我的无人机突然飘了？**
答：多半是进入了姿态模式（卫星信号不足或指南针受干扰）。此时飞行器不再锁定水平位置，会随风漂移。应立即降低高度、减少机动，寻找开阔地降落；不要继续飞远。

**问：运动挡为什么避障不生效？**
答：运动挡速度过快，避障系统的反应时间与制动距离不足，为保证可控性厂商通常会禁用或降级避障。这是设计取舍，不是故障。
