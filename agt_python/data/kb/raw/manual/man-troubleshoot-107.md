# 常见故障排查手册

## 一、按症状快速索引

| 症状 | 最可能原因 | 参见 |
|---|---|---|
| 电机无法启动 / 无法解锁 | 指南针未校准、IMU 未就绪、卫星不足、限飞区 | §2.1 |
| 起飞后自动漂移 | 进入姿态模式、指南针干扰 | §2.2 |
| 图传卡顿、黑屏 | 信号遮挡、天线朝向错误、信道干扰 | §2.3 |
| 云台抖动、画面倾斜 | 云台未自检、锁扣未取下、校准漂移 | §2.4 |
| 飞行中突然下降 | 电压骤降、电池老化、低温 | §2.5 |
| 提示「已达最大飞行高度」 | 限高设置、管制空域限制 | §2.6 |
| 返航点错误 / 返航飞错方向 | 卫星不足即起飞、指南针干扰 | §2.7 |

## 二、逐项处置

### 2.1 电机无法启动

**检查顺序**：
1. 是否已完成指南针校准（App 状态栏是否有红色提示）
2. IMU 是否预热完成、姿态球是否正常
3. 卫星数是否足够（一般需 ≥ 10 颗，且返航点已刷新）
4. 是否处于限飞区/禁飞区（App 会提示）
5. 遥控器与飞行器是否已对频、遥控器是否已拨到正确挡位
6. 电池是否插紧、电量是否足够

**注意**：任何一项安全自检未通过时，电机都不会启动。这是保护机制，不要试图绕过。

### 2.2 起飞后自动漂移

**判断**：若 App 提示进入姿态模式，或飞行器不再自动锁定位置，随风漂移。
**处置**：
1. 立即降低高度，减少水平机动
2. 若遥控信号正常，手动操纵在最近的开阔地降落
3. 落地后远离金属与磁源，重新校准指南针
4. 检查指南针数值是否正常后再起飞

### 2.3 图传卡顿或黑屏

**排查**：
1. **天线朝向**：天线平面应垂直向上并指向飞行器，避免天线尖端正对飞行器
2. **遮挡**：飞手与飞行器之间是否有建筑、山体、树冠遮挡
3. **距离**：是否超出图传有效距离（受环境与法规限制）
4. **信道干扰**：切换图传频段/信道；关闭周围同频设备（路由器、其它遥控器）
5. **设备发热**：移动设备过热会降频，导致画面卡顿
6. **线材**：连接线松动或损坏也会导致画面异常

**处置原则**：图传中断时不要慌，先保持当前姿态，缓慢升高以脱离遮挡，或等待自动返航触发。

### 2.4 云台抖动或画面倾斜

1. 检查云台保护锁扣是否已取下（未取下会导致电机受损）
2. 开机时云台是否完成自检动作（未激活状态下开机云台不会自检）
3. 尝试云台自动校准
4. 检查减震球是否老化、断裂
5. 若摔机后出现，可能是云台排线或电机损伤，需送修

### 2.5 飞行中突然下降

**原因**：电压骤降。常见于低温环境、电池老化、大电流机动（运动挡满杆爬升）。
**处置**：
1. 立即减小机动，降低功率需求
2. 就近降落，不要试图返航到远处
3. 落地后检查电池温度、外观、电芯压差
4. 更换电池或对电池做健康度检测

### 2.6 提示达到最大飞行高度

1. 检查 App 中的限高设置（可能被设置为固定值）
2. 确认是否处于管制空域，真高 120 米以上属管制空域，未经批准不得飞行
3. 部分地区有地理围栏限制
4. **不要尝试通过修改参数绕过限制**——这既是技术风险也是合规风险

### 2.7 返航点错误或返航方向错误

1. 起飞前确认 App 提示「返航点已刷新」
2. 若飞行中出现指南针干扰，**不要依赖自动返航**
3. 落地后重新校准指南针，并检查是否有磁源干扰

## 三、通用原则

1. **先落地再排查**：任何异常的第一优先级是让飞行器安全落地，不要在空中边飞边调试
2. **不要重复尝试**：同一动作连续失败两次以上，说明是系统性问题，应停止操作检查
3. **记录现象**：截图 App 提示、记录时间与地点，便于送修与回溯
4. **不擅自拆机**：拆机会导致失去保修，且可能造成进一步损伤
5. **不绕过安全机制**：所有自检拦截都有其安全含义
