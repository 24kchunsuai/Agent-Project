# 图传信号与遥控链路优化

## 一、链路构成

无人机与被控端之间通常有两条链路：

1. **遥控链路（上行）**：遥控器 → 飞行器，发送操控指令。**断开会触发失控保护**
2. **图传链路（下行）**：飞行器 → 遥控器/移动设备，回传画面与遥测数据

两者通常一体工作，但稳定性受不同因素影响。

## 二、影响信号质量的主要因素

| 因素 | 影响机制 | 优化方法 |
|---|---|---|
| 天线朝向 | 天线尖端方向是信号盲区 | 天线平面垂直向上，与飞行器方向保持垂直关系 |
| 遮挡 | 建筑、山体、树冠吸收/反射信号 | 保持视距（LOS）飞行，必要时升高高度 |
| 距离 | 信号随距离衰减 | 控制在有效图传距离内，留出余量 |
| 电磁干扰 | 基站、高压线、Wi-Fi 密集区 | 更换频段/信道，远离干扰源 |
| 机身姿态 | 飞行器天线方向随姿态变化 | 避免长时间急转、倒飞导致天线指向劣化 |
| 设备性能 | 移动设备过热降频 | 减少后台应用，避免阳光直射设备 |

## 三、天线使用要点

1. **不要将天线正对飞行器**——天线尖端正对目标时信号最弱，应让天线平面朝向飞行器
2. 双天线机型应保持两根天线**平行且竖直**
3. 长距离飞行时抬高遥控器，避免身体与地面遮挡
4. 不要让天线被握持的手掌包围

## 四、视距飞行（LOS）原则

多数地区的法规要求无人机在**肉眼可见范围内**飞行（视距内运行，VLOS）。这既是合规要求，也是链路安全的保障：

- 图传再好，也依赖无线电直线传播
- 一旦进入建筑物背面、山体后侧，信号会急剧衰减
- 超视距飞行需要相应的**超视距等级**资质（CCAR-92 部规定，超视距等级可签注在小型或中型操控员执照上）

## 五、图传参数的理解

| 参数 | 含义 | 调整建议 |
|---|---|---|
| 分辨率/帧率 | 画面规格 | 高清优先画质，低分辨率优先流畅度 |
| 码率 | 单位时间数据量 | 高码率画质好但抗干扰差；干扰大时降码率 |
| 频段 | 工作频率（如 2.4GHz / 5.8GHz） | 2.4GHz 穿透好、5.8GHz 速率高 |
| 信道 | 频段内的细分通道 | 自动或手动选择干扰最小的信道 |

## 六、常见问题

**问：图传画面卡顿但还能控制，怎么办？**
答：说明遥控链路正常、图传链路质量下降。应先降低码率或切换信道，同时减小飞行距离、抬高飞行高度脱离遮挡，尽快返航。

**问：信号丢失后飞行器会怎样？**
答：取决于失控保护设置。设为「返航」时，飞行器会在信号中断超过设定时间后自动返航；设为「悬停」则原地等待信号恢复；设为「降落」会就地下降（在陌生环境极危险）。开阔环境建议设为返航。

**问：为什么城市里图传距离比郊外短很多？**
答：城市中建筑物遮挡、Wi-Fi 与基站密集，电磁环境复杂，信号衰减与干扰远高于开阔郊外。厂商标称的图传距离通常在无干扰、无遮挡的测试环境下测得，实际使用应大幅打折。
