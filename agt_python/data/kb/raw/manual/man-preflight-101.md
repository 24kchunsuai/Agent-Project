# 起飞前检查清单与场地评估

## 一、为什么起飞前检查不能省

绝大多数飞行事故的诱因在起飞前就已埋下：指南针未校准导致姿态漂移、电池老化导致空中掉电、桨叶裂纹导致射桨、场地选择不当导致撞障。飞行安全主体责任在操控者，检查是最低成本的预防手段。

## 二、机身与机械检查

1. **桨叶**：逐片检查有无裂纹、缺口、变形、松动。桨叶是消耗品，有损伤必须整套更换（不要新旧混装）
2. **机臂与机身**：折叠机型展开到位并锁紧卡扣，检查机臂根部有无裂痕
3. **云台与相机**：**先取下云台保护锁扣再开机**——未取锁扣开机会造成电机受损，影响使用寿命，起飞后严重影响飞行安全
4. **电机**：手动轻转桨叶，感受是否顺畅、有无异响或卡顿
5. **起落架/脚架**：有无变形，减震球是否老化
6. **螺丝与紧固件**：重点检查机臂、电机座

## 三、电池检查

1. 电池外观：有无**鼓包**、破损、漏液、极片腐蚀。鼓包电池一律停用
2. 电量：起飞前充至 **90% 以上**（部分机型建议充满并静置至常温）
3. 温度：电池温度低于 15℃ 或高于 40℃ 时不宜起飞，低温会导致电压骤降
4. 卡扣：电池是否完全插入并有明显卡合反馈
5. 循环次数：接近或超过厂商标称循环次数（通常 200 次左右）的电池应降级为地面使用

## 四、遥控器与图传

1. 遥控器电量充足（建议 50% 以上，长途作业充满）
2. 天线朝向正确：**天线平面垂直向上并指向飞行器方向**，避免天线正对飞行器（尖端朝向是信号盲区）
3. 移动设备/带屏遥控器电量与存储充足
4. 已完成对频，图传画面正常无卡顿
5. 移动设备已开飞行模式（有 SIM 卡的设备），避免来电打断操作

## 五、指南针与 IMU

1. 指南针校准状态正常，App 无红色提示
2. 更换场地（尤其是相距较远或磁场环境差异大的场地）后应重新校准
3. IMU 预热完成，姿态球显示正常
4. 校准时应远离钢筋、磁铁、金属结构、地下管线

## 六、场地与环境评估

| 评估项 | 要求 |
|---|---|
| 净空 | 起降点方圆 5 米内无人员、无遮挡物；起飞方向上无高大障碍 |
| 地面 | 平整、无砂石（避免吸入电机）、非反光严重材质（影响下视定位） |
| 人群 | 避开人群密集区，围观者保持 10 米以上距离 |
| 电磁环境 | 远离高压线、基站、雷达站、大型金属结构 |
| 天气 | 风速在机型抗风能力内、无降雨、能见度良好 |
| 空域 | 已确认处于适飞空域，或已取得管制空域飞行批准 |
| 卫星 | 卫星数 ≥ 10 颗，GPS 信号良好且已刷新返航点 |

## 七、合规前置项

- [ ] 已在 UOM 平台完成实名登记，机身贴有二维码
- [ ] 机型类别对应的执照要求已满足
- [ ] 责任保险已投保（经营性活动或小型以上机型）
- [ ] 已查询空域信息，无临时管制公告
- [ ] 飞行计划已获批准（如需要）

## 八、起飞前的最后确认

1. App 状态栏**无红色警告**（如指南针干扰、IMU 异常、限飞提示）
2. 返航点已刷新且位置正确
3. 返航高度设置高于航线沿途最高障碍物
4. 低电量返航阈值已按任务设置
5. 周围无人，发出起飞提示音后离手，先**悬停观察 10~30 秒**确认姿态稳定再执行任务
