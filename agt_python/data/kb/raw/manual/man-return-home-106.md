# 自动返航逻辑与失控保护设置

## 一、返航点（Home Point）

返航点是飞行器记录并在触发返航时飞回的位置。

**刷新时机**：
- 起飞时自动记录（以起飞点为准，需卫星信号良好）
- 飞行中可手动刷新为「当前飞行器位置」或「遥控器位置」

**关键提醒**：如果卫星数不足就起飞，返航点可能记录错误或未记录，一旦触发返航会飞到错误位置。**起飞前务必确认 App 提示「返航点已刷新」**。

## 二、返航高度的设置

这是最容易被忽视、后果最严重的设置。

**返航逻辑**：飞行器先爬升到设定的返航高度，再水平飞回返航点，最后下降。

**设置原则**：
1. 返航高度必须**高于航线沿途最高障碍物**（建筑、塔、树、山体）
2. 常见默认值：60 米、100 米或 120 米，按机型与地区不同
3. 在城市环境飞低空时，应按实际最高建筑设置，例如周边有 150 米高楼，返航高度应设为 160 米以上
4. 注意：返航高度**过高**会消耗更多电量（爬升耗电大），长途返航可能不够电
5. 同时注意法规：真高 120 米以上属于管制空域，返航高度设置应结合合规要求综合评估

## 三、触发返航的情形

| 触发源 | 说明 |
|---|---|
| 手动触发 | App 中点击返航按钮，或遥控器返航键长按 |
| 低电量返航 | 电量降至设定阈值（常见 20% 左右）自动触发 |
| 严重低电量 | 电量极低时强制降落（不可取消），直接在当前点上空下降 |
| 信号丢失返航 | 遥控信号中断超过设定时间（常见数秒）自动触发 |
| 一键返航 | 智能功能中的返航 |

## 四、返航过程中的操控

- 触发返航后**推杆可以取回控制权**（多数机型的操作逻辑），此时返航中止，恢复手动控制
- 若要取消返航，按 App 或遥控器对应按键
- 返航途中飞行器会自动避障（若机型支持且模式允许）
- 返航途中尽量不要反复切换，避免状态混乱

## 五、失控保护设置建议

1. **信号丢失行为**：设为「返航」而非「悬停」或「降落」（在开阔区域返航最安全；若在室内或信号不可避免中断的场景，需按实际情况选择）
2. **低电量返航阈值**：按任务时长与距离设置，长途作业可提高到 30%
3. **返航高度**：按现场最高障碍物 + 余量设置
4. **避障行为**：设为「刹停」或「绕行」；设为「关闭」可提高飞行连贯性但风险显著增大
5. **最大飞行高度/距离**：建议按法规与任务需要设置限值，作为误操作的兜底

## 六、常见错误

- ❌ 起飞后才发现返航点没刷新
- ❌ 返航高度低于沿途障碍物 → 返航过程中撞楼
- ❌ 在有风天气依赖返航 → 逆风返航耗电剧增，可能回不来
- ❌ 低电量时还在远处拍 → 严重低电量触发的强制降落不可取消
- ❌ 在不适合返航的环境（室内、桥下、密林）仍设为「信号丢失返航」

## 七、常见问题

**问：返航时飞行器撞到东西了，是我操作问题吗？**
答：多数情况是返航高度设置不当。返航逻辑是「先爬到返航高度再水平返回」，如果返航高度低于沿途障碍物，就会撞上。起飞前应按现场最高障碍物设置返航高度。

**问：返航途中可以接手吗？**
答：可以。多数机型在返航状态下推杆即可取回控制权，但需要在 App 或说明中确认具体机型的逻辑，避免误判。

**问：低电量返航能取消吗？**
答：低电量返航通常可以取消或接手，但**严重低电量触发的强制降落不可取消**。这就是必须预留电量余量的原因。
