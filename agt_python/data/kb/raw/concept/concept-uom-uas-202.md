# 术语辨析：UOM 与 UAS 到底有什么区别

> 这两个缩写经常被混为一谈。一句话区分：**UOM 是一个"平台"（办事系统），UAS 是"系统英文缩写 / 登记号前缀"（一个编号的组成部分）**。

## 一、UOM：一个平台

UOM 指中国民航局的**民用无人驾驶航空器综合管理平台**，网址是 **https://uas.caac.gov.cn**（注意：域名里是 uas，平台简称是 UOM，这也是很多人混淆的来源）。

在 UOM 平台上可以办理的事：

- **实名登记**：所有者登记无人机，获取实名登记号
- **飞行活动申请**：在管制空域飞行前提交申请
- **空域查询**：查询适飞空域与管制空域
- **操控员执照**：执照的考试、核发与管理

一句话：**办无人机相关的"手续"，去的地方叫 UOM**。

## 二、UAS：一个缩写 / 登记号前缀

UAS 是 **Unmanned Aircraft System（无人驾驶航空器系统）** 的英文缩写，泛指"无人机 + 地面站 + 数据链"组成的整个系统。

在实名登记语境下，UAS 有一个具体形态：**实名登记号码以 UAS 开头**。登记号共 11 位，格式为 `UAS` + 8 位（阿拉伯数字、罗马字符大写字母或二者的组合）。例如：`UAS2026AB12`。

## 三、对照表

| 对比项 | UOM | UAS |
|---|---|---|
| 本质 | 民航局的综合监管**服务平台** | 无人驾驶航空器**系统的英文缩写** |
| 具体形态 | 网站 https://uas.caac.gov.cn | 实名登记号的**前缀**（UAS + 8 位，共 11 位） |
| 什么时候打交道 | 实名登记、飞行申请、执照管理 | 拿到登记号、机身标注、填报信息时 |
| 类比 | 政务服务大厅 | 办出来的证件号码 |

## 四、常见混淆点

1. **域名是 uas.caac.gov.cn，平台却叫 UOM**：域名沿用历史系统名，平台是后来整合的，名字与域名不一致不代表是两个系统。
2. **"产品注册"不等于"实名登记"**：厂商 App 里的激活/注册是厂商体系，与民航局实名登记无关；实名登记必须在 UOM 平台完成。
3. **UAS 开头的是登记号，不是执照号**：操控员执照有自己的编号体系，与实名登记号无关。
