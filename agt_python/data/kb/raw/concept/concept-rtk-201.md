# RTK 技术原理

> 本篇为概念科普文档，回答「RTK 是什么原理」。RTK 不只是某个机型型号后缀，而是一套完整的定位技术。

## 一、RTK 是什么

RTK（Real-Time Kinematic，实时动态载波相位差分定位）是一种卫星定位增强技术。普通无人机靠 GPS/北斗单点定位，误差在**米级**（水平约 1~3 米）；而 RTK 可以把定位精度提升到**厘米级**（水平约 1 cm + 1 ppm）。

## 二、普通卫星定位为什么只有米级精度

卫星信号从 2 万公里高空到达地面，会经历多种误差源：

- **电离层延迟**：信号穿过电离层时速度发生变化
- **对流层延迟**：低空的温湿度引起折射
- **星历误差与卫星钟差**：卫星自身位置和时钟的微小偏差
- **多路径效应**：信号在建筑物、水面反射后叠加

单点定位无法消除这些误差，所以普通定位只能精确到米级。

## 三、RTK 的核心原理：载波相位 + 差分改正

RTK 之所以能到厘米级，靠两件事：

1. **载波相位测量**：不只用测距码，而是测量卫星载波（波长仅约 19 cm）的相位。相位测量的分辨率远高于测距码，相当于用更细的"刻度尺"量距离。
2. **基准站差分改正**：在已知精确坐标的位置放一台**基准站**，它实时解算观测误差，并把改正量通过数据链路（电台或 4G/5G 网络）发给附近的**移动站**（无人机）。由于两站距离较近时误差高度相关，移动站用改正量修正自己的观测值，大部分公共误差被抵消。

一个直观类比：两个人在同一个操场看同一场雾，一人站在已知位置的旗杆旁，他测出"雾让目测距离偏了多少"，用无线电告诉另一人，另一人据此修正自己的目测结果。

## 四、关键概念

- **Fix / Float 解**：载波相位存在整周模糊度问题。模糊度确定后称为 **Fix（固定解）**，厘米级精度；未确定时为 **Float（浮点解）**，精度亚米级。飞控 OSD 上显示 RTK 状态时，Fix 才是达标状态。
- **收敛时间**：从开机到获得 Fix 解所需的时间，通常几十秒到几分钟，与观测环境相关。
- **数据链路**：基准站到移动站的改正信息通道，可以是自架电台（数传），也可以是网络 RTK 服务（如千寻位置等 CORS 服务，通过 4G 传输）。

## 五、无人机上 RTK 的典型用途

- **精准悬停与航迹复飞**：定位准确且可重复，适合测绘、巡检的航线飞行
- **测绘建模**：免像控或减少像控点，直接输出高精度成果
- **植保作业**：按精确航线喷洒，不重喷、不漏喷
- **行业机型标配**：大疆 Matrice 300 RTK / 350 RTK 等行业机型内置 RTK 模块，机身命名中的"RTK"即指搭载此能力

## 六、局限性

- **遮挡环境失效**：高架桥下、密林、峡谷等 GNSS 信号被遮挡的场景，RTK 会失锁退回普通定位
- **依赖基准站覆盖**：网络 RTK 服务需要处于服务商的覆盖范围；自架电台距离有限（一般数公里）
- **不改变避障能力**：RTK 只解决"我在哪"，不解决"旁边有什么"
