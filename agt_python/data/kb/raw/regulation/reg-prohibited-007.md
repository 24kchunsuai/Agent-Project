# 禁止行为与飞行安全主体责任

## 一、明确禁止的八类行为

《无人驾驶航空器飞行管理暂行条例》规定，禁止利用无人驾驶航空器实施下列行为：

1. **违法拍摄军事设施、军工设施或者其他涉密场所**
2. 扰乱机关、团体、企业、事业单位工作秩序或者公共场所秩序
3. 妨碍国家机关工作人员依法执行职务
4. 投放含有违反法律法规规定内容的宣传品或者其他物品
5. 危及公共设施、单位或者个人财产安全
6. 危及他人生命健康，非法采集信息，或者侵犯他人其他人身权益
7. 非法获取、泄露国家秘密，或者违法向境外提供数据信息
8. 法律法规禁止的其他行为

**特别提示**：禁止外国无人驾驶航空器或者由外国人员操控的无人驾驶航空器在我国境内实施测绘、电波参数测试等飞行活动。

## 二、飞行安全主体责任

条例第二十五条规定：组织无人驾驶航空器飞行活动的单位或者个人应当遵守有关法律法规和规章制度，**主动采取事故预防措施，对飞行安全承担主体责任**。

这意味着：

- 飞行安全的第一责任人是组织者/操控者，不是厂商、不是平台
- 需要主动预防，而非被动应对——起飞前的检查、环境评估、应急处置准备都属于责任范围
- 出现事故时，主体责任的履行情况（是否做了检查、是否有预案）会成为重要判断依据

## 三、识别与监管要求

1. 除微型以外的无人驾驶航空器飞行时，操控人员应确保无人机能按规定向一体化综合监管服务平台报送识别信息
2. 微型、轻型、小型无人驾驶航空器在飞行过程中应当**广播式自动发送识别信息**
3. 国家空中交通管理领导机构统筹建设**无人驾驶航空器一体化综合监管服务平台**，对全国无人驾驶航空器实施动态监管与服务
4. 有关部门按职责分工采集无人机生产、登记、使用的有关信息，依托平台共享并保障信息安全

## 四、无线电与频率管理

生产、维修、使用民用无人驾驶航空器系统，应当遵守无线电管理法律法规以及国家有关规定。

**豁免情形**：民用无人驾驶航空器系统使用国家无线电管理机构确定的特定无线电频率，且有关无线电发射设备取得无线电发射设备型号核准的，**无需取得无线电频率使用许可和无线电台执照**。

## 五、召回与产品责任

- 微型、轻型、小型无人机系统投放市场后发现存在缺陷的，生产者、进口商应当停止生产、销售，**召回缺陷产品**，并通知有关经营者、使用者停止销售、使用
- 中型、大型无人机系统不能持续处于适航状态的，由民航主管部门依照适航管理规定处理
- 对已取得适航许可的系统进行**重大设计更改**并拟用于飞行活动的，应当重新申请适航许可
- 对微型、轻型、小型无人机系统进行**改装**的，应当符合有关强制性国家标准

## 六、实操检查清单（飞行前合规自查）

- [ ] 无人机已在 UOM 平台完成实名登记，机身贴有登记二维码
- [ ] 机型类别对应的执照要求已满足（小型以上须持证）
- [ ] 已确认起飞点、航线是否处于适飞空域（真高 120 米以下且非管制区域）
- [ ] 如需在管制空域飞行，已提前 1 日 12 时前提交申请并获批准
- [ ] 已在计划起飞 1 小时前报告并获确认
- [ ] 责任保险已投保（经营性活动，或小型以上机型）
- [ ] 已核对是否有临时管制公告
- [ ] 拍摄内容不涉及军事设施、涉密场所
- [ ] 已评估现场人员安全与隐私影响

## 七、常见问题

**问：在自家小区飞会不会违法？**
答：关键看空域属性和现场条件。若在适飞空域、机型属微型/轻型、未侵犯他人权益，通常可行；但若小区邻近机场、军事管理区等管制区域，或涉及噪音扰民、隐私拍摄，则可能违规。

**问：拍摄的内容被平台要求删除，是法规问题吗？**
答：可能是。若拍摄涉及军事设施、涉密场所等，属于条例明确禁止的行为，属于法规层面的违法，而非平台规则问题。
