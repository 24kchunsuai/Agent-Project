# 责任保险要求与违规处罚标准

## 一、强制投保责任保险的情形

《无人驾驶航空器飞行管理暂行条例》第十二条规定：

使用民用无人驾驶航空器从事**经营性**飞行活动，以及使用**小型、中型、大型**民用无人驾驶航空器从事**非经营性**飞行活动，应当依法投保责任保险。

归纳成表格：

| 类别 | 非经营性飞行 | 经营性飞行 |
|---|---|---|
| 微型 | 不需要 | **需要** |
| 轻型 | 不需要 | **需要** |
| 小型 | **需要** | **需要** |
| 中型 | **需要** | **需要** |
| 大型 | **需要** | **需要** |

**判断口诀**：只要沾「商业」，无论什么机型都要投保；只要机型是小型以上，无论商用与否都要投保。

## 二、违规处罚标准

### 2.1 未经实名登记飞行（第 47 条）

民用无人驾驶航空器未经实名登记实施飞行活动的：

- 由公安机关责令改正，可以处 **200 元以下**罚款
- 情节严重的，处 **2000 元以上 2 万元以下**罚款

### 2.2 违规在管制空域飞行（第 19 条、第 51 条）

未经批准操控微型、轻型、小型民用无人驾驶航空器在管制空域内飞行，或者操控模型航空器在空中交通管理机构划定的空域外飞行的：

- 由公安机关责令停止飞行，可以处 **500 元以下**罚款
- 情节严重的，**没收**实施违规飞行的无人驾驶航空器，并处 **1000 元以上 1 万元以下**罚款

### 2.3 未成年人违规（第 17 条、第 50 条）

无民事行为能力人、限制民事行为能力人违反条例操控民用无人驾驶航空器飞行的：

- 由公安机关对其**监护人**处 **500 元以上 5000 元以下**罚款
- 情节严重的，没收实施违规飞行的无人驾驶航空器

### 2.4 其他处置措施

无人驾驶航空器违反飞行管理规定、扰乱公共秩序或者危及公共安全的，空中交通管理机构、民用航空管理部门和公安机关可以依法采取必要**技术防控**、**扣押**有关物品、**责令停止飞行**、**查封**违法活动场所等紧急处置措施。

对空中不明情况和无人机违规飞行，公安机关在条件有利时可以对低空目标实施**先期处置**，并负责违规飞行无人机落地后的现场处置。有关军事机关、公安机关、国家安全机关等单位按职责分工组织查证处置。

## 三、反制设备的管理

- 军队、警察以及按国家反恐怖主义工作领导机构有关规定由公安机关授权的高风险反恐怖重点目标管理单位，可以依法配备无人驾驶航空器**反制设备**，在公安机关或有关军事机关的指导监督下从严控制设置和使用
- 任何单位或者个人**不得非法拥有、使用**无人驾驶航空器反制设备

## 四、运营合格证

使用除微型以外的民用无人驾驶航空器从事飞行活动的单位，应当向民用航空管理部门申请取得**民用无人驾驶航空器运营合格证**，条件包括：

1. 有实施安全运营所需的管理机构、管理人员和符合条例规定的操控人员
2. 有符合安全运营要求的无人驾驶航空器及有关设施、设备
3. 有实施安全运营所需的管理制度和操作规程，保证持续具备按制度和规程实施安全运营的能力
4. 从事经营性活动的单位，还应当为**营利法人**

民用航空管理部门收到申请后应进行**运营安全评估**，据此作出许可或不予许可决定。

**豁免情形**：使用最大起飞重量不超过 150 千克的农用无人驾驶航空器，在农林牧渔区域上方的适飞空域内从事农林牧渔作业飞行活动（常规农用作业），**无需取得运营合格证**。

取得运营合格证后从事经营性通用航空飞行活动，以及从事常规农用无人驾驶航空器作业飞行活动，**无需取得通用航空经营许可证和运行合格证**。

## 五、常见问题

**问：我自己拍视频发抖音算经营性吗？**
答：要看是否以营利为目的、是否形成商业行为。承接商业拍摄、带货等明显以营利为目的的活动，实务中会被认定为经营性飞行，需要投保责任保险。

**问：没有执照飞小型机会怎样？**
答：属于违反条例的操控行为，可能面临责令停止飞行、罚款等处罚；如因操作造成事故，还可能被暂停或撤销相关资格。

**问：被没收的无人机还能要回来吗？**
答：没收是法定处罚措施，一般不予返还。因此合规飞行的成本远低于违规成本。
