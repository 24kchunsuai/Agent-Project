# 无人机选型指南

## 一、选型的第一原则：先把合规成本算进去

很多新手只看性能和价格，忽略合规成本，结果买回来发现「不能飞」或「需要额外资质」。选型应从三个约束同时出发：

1. **重量类别** → 决定执照与适航要求
2. **作业空域** → 决定是否需要飞行申请
3. **用途性质**（自用 / 商用）→ 决定是否需要责任保险与运营合格证

## 二、按用途选择

| 用途 | 推荐类别 | 关键理由 |
|---|---|---|
| 个人旅行记录、日常拍摄 | 微型（< 250 克） | 免执照、便携、多数场景合规门槛最低 |
| 专业航拍、影像创作 | 轻型（空机 ≤ 4kg、最大起飞 ≤ 7kg） | 影像系统与续航明显更强，仍免执照 |
| 行业巡检、测绘 | 小型及以上 | 载荷能力、续航、抗风要求高 |
| 农林植保 | 农用无人机（最大起飞 ≤ 150kg） | 有专门的作业规则，免执照、免运营合格证（需操作证书） |
| 物流运输 | 中型及以上 | 需适航许可、运营合格证、操控员执照 |

## 三、核心性能指标怎么看

### 3.1 续航时间

标称续航通常在**风洞无风、匀速前飞、避障设为刹停**的理想条件下测得。实际悬停与机动飞行会明显缩短（有时只有标称值的 60%~70%）。**评估任务可行性时按标称值的七折估算较稳妥。**

### 3.2 抗风能力

标称的是**极限值**，不是推荐使用值。建议按标称值的 70% 作为实际作业上限。抗风不足会导致返航时逆风耗电剧增，甚至无法返航。

### 3.3 图传距离

厂商标称通常基于无干扰、无遮挡的测试环境（如 FCC 标准下的开阔场景）。城市环境中因建筑遮挡与电磁干扰，实际可用距离往往只有标称的一小部分。

### 3.4 影像系统

关键看传感器尺寸、光圈、是否支持对数（Log）色彩、是否有可变光圈与多焦段。参数之外还要看镜头素质与云台稳定性。

### 3.5 避障能力

全方位避障显著提升复杂环境的安全性，但会增重并增加成本。轻量化机型常在此处取舍。**注意运动挡下避障可能失效。**

## 四、重量分级的关键分界线

| 分界线 | 跨越后果 |
|---|---|
| 250 克（微型上限） | 从微型变为轻型：在管制空域内飞行需经培训合格 |
| 4 千克 / 7 千克（轻型上限） | 进入小型：**必须持有操控员执照**，且责任保险成为强制 |
| 25 千克（小型上限） | 进入中型：还需取得**适航许可** |
| 150 千克（中型上限） | 进入大型：需适航许可；融合飞行须经批准 |

**实务建议**：如果作业需求接近分界线，宁可选低一档的类别——合规成本（时间、资质、保险、审批）往往远超性能收益。

## 五、选型检查清单

- [ ] 主要作业场景是什么？室内/室外、城市/郊野、视距内/超视距
- [ ] 需要什么载荷（相机规格、挂载设备重量）
- [ ] 单次任务需要多长续航，是否需要多电池轮换
- [ ] 现场常见风速多少，机型抗风是否留有余量
- [ ] 作业地点是否属于管制空域，是否需要飞行申请
- [ ] 是否属于经营性活动，是否满足保险与资质要求
- [ ] 是否需要售后与备件支持（行业机型的服务网络差异大）
- [ ] 总拥有成本：机身 + 电池 + 配件 + 保险 + 培训 + 审批时间

## 六、常见问题

**问：新手第一台买微型还是轻型？**
答：若只是练习和日常记录，微型机合规门槛最低、成本低、摔机代价小，适合入门；若确认要往影像创作发展，可考虑轻型，但需接受更高的成本和更严的合规要求。

**问：为什么同样标称 30 分钟续航，实际差别很大？**
答：测试条件不同。标称值通常在无风、匀速、避障刹停的理想状态下测得；实际飞行中的悬停、爬升、机动、逆风都会显著增加功耗。
