## §0 前置条件

- [ ] 仓库完整（含 `VERSION`、`deploy/`、三端代码目录 `agt_python` / `agt_backend` / `agt_web`）

- [ ] **进程在 session 0**：PowerShell 执行
      `(Get-Process -Id (Get-NetTCPConnection -LocalPort 8000 -State Listen).OwningProcess[0]).SessionId`
      期望：`0`（S4U 非交互；若为 1 说明没用计划任务启动，关窗口即死）
- [ ] **四探针（业务级）**：

## §2 鉴权与安全（S-1 信任边界）

- [ ] **8000 应用层密钥**：`curl -s --noproxy '*' http://127.0.0.1:8000/v1/kb/stats`
      期望：返回体 `{"code":4010,...}` 且 **HTTP 状态仍为 200**（项目约定：业务码在 body）；带 `X-Agent-Key` 头重试 → `"code":2000`
- [ ] **8000 网络层收口**：`netstat -ano | grep ":8000" | grep LISTENING`
      期望：只有 `127.0.0.1:8000`，**没有** `0.0.0.0:8000`（外网/其它机器不可达）
- [ ] **8080 只认 Bearer**：`curl -s --noproxy '*' http://127.0.0.1:8080/v1/agent/metrics/overview`
      期望：`"code":4010`（未登录）；带 `Authorization: Bearer <8080登录token>` 重试 → `"code":2000`
- [ ] **密钥不落日志**：`grep -r "AGENT_SHARED_KEY\|sk-" deploy/logs/*.log | head`
      期望：日志中密钥只以掩码形态出现（如 `Z9***Ak(len=43)`），无明文

## §5 核心链路一键演示（E-15，登录 → RAG → 业务工具 → 确认门 → 看板）

- [ ] **一键全绿**：`$PY scripts/demo.py`
      期望：**21/21 通过、退出码 0**。六步含义：
      1. 登录（8080 统一鉴权）→ token
      2. 链路健康（8080→8000 穿透 + 全组件聚合）
      3. RAG 问答（评测集 eval-002：答出 UOM 平台与官网，`ragDecision=kept`、citations ≥1）
      4. 业务工具（`drone_query` 真实调用，toolTrace 非空，答出设备数据）
      5. 确认门（写操作被拦截+数据零改动 → 回「确认」真实落库并回执 → 回「取消」不执行 → 收尾自动删除演示任务）
      6. 看板数据（metrics/overview 与 metrics/costs 均 code=2000，costs 含 totals/byModel）
      > 确认门一节会真实创建并删除一个 `E15DEMO-` 前缀任务（可重跑）；取消路径不碰任何存量数据。
- [ ] **分步人工复核（可选抽查）**：
      | 链路 | 命令（先登录拿 token） | 期望 |
      |---|---|---|
      | 对话 | `curl -s --noproxy '*' -X POST http://127.0.0.1:8080/v1/agent/chat -H "Authorization: Bearer $T" -H "Content-Type: application/json" -d '{"message":"无人机实名登记在哪个平台办理？","sessionId":"accept-1","userId":1}'` | `data.ragDecision="kept"`、`citations` 数组非空、正文含 `UOM` |
      | 流式 | 同上改 POST `/v1/agent/chat/stream` | SSE 逐字 `delta` 事件，收尾 `done` 事件 `usage` 非空（`usageSource":"api"`） |
      | 看板 | `curl -s --noproxy '*' http://127.0.0.1:8080/v1/agent/metrics/costs -H "Authorization: Bearer $T"` | `"code":2000`、`data.totals`、`data.byModel` 存在 |
- [ ] **前端可视化**：浏览器打开 `http://127.0.0.1:9090` 登录 admin，进入「数据看板」
      期望：总览 / 会话 / 成本与配额 / 知识缺口 / 前端错误各页正常渲染；顶栏状态灯绿或黄（黄=组件级降级，悬停见明细）
- [ ] **轻量压测（T-1，可选加测）**：`$PY scripts/loadtest.py`
      期望：末行 **PASS**——六只读场景 0 错误（错误率判定线 1%）、RPS 三位数、压后 `ops/health` 顶层 `up`。

      对话 p50 ≈5.7s（外部 LLM 主导）均属预期。⚠️ 对话走真实外部 LLM，成本敏感用 `--chat 0`
